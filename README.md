## 🌷 About This Project

Baseball Stats Analyzer is a web application built with Python and Flask. It stores player data in an SQLite database and calculates important batting statistics.

This project is a hands-on journey to learn web development, database management, and baseball analytics step by step. ♡

## 🍀 Features

| Feature | Description |
|:--|:--|
| ⚾ **AVG** | Calculate batting average |
| 🌱 **OBP** | Calculate on-base percentage |
| 🌷 **SLG** | Calculate slugging percentage |
| ✨ **OPS** | Calculate on-base plus slugging |
| 🏆 **Leaderboard** | Rank players by AVG, OBP, SLG, or OPS |
| 📖 **Player Details** | View individual player statistics |
| 🗃️ **SQLite Database** | Store and manage player records |
