## 🧺 01. About This Project
### 프로젝트 소개

> 🌱 **EN**  
> Baseball Stats Analyzer is a web application built with Python and Flask. It stores player records and calculates batting statistics using an SQLite database.

> 🌱 **KR**  
> Baseball Stats Analyzer는 Python과 Flask로 개발한 야구 선수 기록 분석 웹 애플리케이션입니다. SQLite 데이터베이스에 선수 기록을 저장하고, 주요 타격 지표를 계산하며, 선수별 기록과 순위를 확인할 수 있습니다.

## 🍃 02. My Little Scorebook
### 주요 기능

| Sticker | Feature | 기능 |
|:---:|:---|:---|
| ⚾ | **AVG** | 타율 계산 |
| 🌱 | **OBP** | 출루율 계산 |
| 🌷 | **SLG** | 장타율 계산 |
| ✨ | **OPS** | 출루율 + 장타율 |
| 🏆 | **Leaderboard** | 타격 지표별 선수 순위 |
| 📖 | **Player Details** | 선수별 상세 기록 |
| 🧸 | **SQLite Database** | 선수 데이터 저장 및 관리 |
